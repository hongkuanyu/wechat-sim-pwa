扫码安装

用手机扫一扫，直接打开安装

安卓用任意浏览器扫码 · 苹果用系统相机或微信扫码后选「在Safari中打开」

方法一：浏览器直接安装（推荐）

1. 打开网址或扫码进入应用
2. 点击页面顶部弹出的绿色「安装」横幅
3. 如果没有横幅：点浏览器右上角 ⋮ 菜单
4. 选择「安装应用」或「添加到桌面」
5. 桌面出现绿色图标，点开即可全屏使用
打开应用

方法二：下载 APK 安装包

下载 APK 文件，直接点击安装。安装时手机会提示「未知来源」，允许即可。

APK 大小约 885KB · 支持 Android 7.0+
本质是 TWA 壳，首次打开需联网

各浏览器安装路径

Edge：⋮ → 安装应用

小米浏览器：⋮ → 更多工具 → 安装应用

vivo：底部菜单 → 添加到桌面 → 安装
三星：☰ → 安装应用
QQ浏览器：菜单 → 添加到桌面 → 安装为应用

微信内置浏览器、夸克浏览器不支持安装，请换用上述浏览器

Safari 添加到主屏幕

1. 用 Safari 打开应用网址（其他浏览器不行）
2. 点底部中间的 「分享」按钮（方块+向上箭头）
3. 向下滑动，找到 「添加到主屏幕」
4. 名称填「微信聊天」→ 点右上角 「添加」
5. 桌面出现绿色图标，点开全屏运行
用 Safari 打开

注意事项

必须使用 Safari 浏览器
