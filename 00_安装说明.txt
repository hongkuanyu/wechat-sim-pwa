【目录结构】
  微信聊天模拟_PWA/
   └ index.html           主程序（HTML+CSS+JS 单文件，已内嵌全部逻辑）
   └ manifest.webmanifest PWA 清单（应用名称/图标/全屏参数）
   └ sw.js                Service Worker（离线缓存核心，安装后断网可运行）
   └ 一键启动服务器.bat            本机访问用（双击启动）
   └ 一键启动服务器(局域网公开).bat 手机在同一WiFi下安装用
   └ 一键安装.bat                   自动启动+自动打开浏览器+显示IP
   └ 一键部署到公网.bat             部署到GitHub Pages（本项目已部署完成，无需再运行）

【公网安装 · 零依赖 · 不用电脑 · 不用同WiFi】
  只需在手机浏览器输入网址：
    https://hongkuanyu.github.io/wechat-sim-pwa/

  ── 安卓手机（所有主流浏览器都支持，任选一个）──

  【推荐 · Chrome】
    1. 打开网址
    2. 页面顶部会弹绿色横幅 → 点「安装」（一步完成）
       如果没看到横幅：右上角 ⋮ → 「安装应用」

  【Edge 浏览器】
    右上角 ⋮ → 「安装应用」

  【三星浏览器】
    右上角 ☰ → 「安装应用」

  【华为浏览器】
    右下角 ▤ 按钮 → 「添加到桌面」 → 弹出提示时点「安装」

  【小米 / 红米浏览器】
    右上角 ⋮ → 「更多工具」 → 「安装应用」

  【OPPO 浏览器】
    底部菜单按钮 → 「添加到桌面」 → 「安装到桌面」

  【vivo 浏览器】
    底部菜单 → 「添加到桌面」 → 「安装」

  【QQ 浏览器】
    底部/右上角菜单 → 「添加到桌面」 → 「安装为应用」

  【UC 浏览器】
    菜单按钮 → 「添加收藏和快捷方式」 → 「添加到桌面」 → 「安装」

  安装完成后：桌面出现绿色「微」字图标，像普通 App 一样全屏运行，
  没有地址栏。首次加载成功一次后，飞机模式（断网）也能点开使用。

  ── 苹果 iPhone / iPad（必须用 Safari）──

  1. 用 Safari 打开上面的公网网址
  2. 点浏览器底部中间的「分享」按钮（方形+向上箭头）
  3. 向下滑动菜单，找到「添加到主屏幕」
  4. 命名为「微信聊天」→ 点右上角「添加」
  5. 桌面出现绿色图标，点开全屏运行。

  注意：iOS 上 Chrome/Edge/其他浏览器都不支持安装 PWA，必须用 Safari。

【快速运行（电脑上本地打开）】
  Windows：双击「一键启动服务器.bat」，浏览器会自动打开。
  命令行：python -m http.server 8765  → 打开 http://127.0.0.1:8765/index.html

  注意：直接双击 index.html（file:// 协议）聊天/联系人功能可以用，
        但 Service Worker 无法注册，所以不能安装成 App、也不能离线缓存。
        想要 App 模式/离线缓存，必须走上面的 HTTP 或公网方式。

【功能说明】
 ✔ 多联系人：顶栏输入框回车或点 ➕ 添加联系人（弹窗里可顺便设头像）
 ✔ 自定义头像：
    - 我的头像：点左上角深色导航条里的绿色头像进入修改
    - 联系人头像：联系人列表里点某一行的头像方块进入修改
    - 图片会自动压缩为 128px JPEG，约 5~15KB/张，节省 localStorage
 ✔ 特殊消息卡片：转账（自定义金额）、红包、语音通话、视频通话
 ✔ 模拟好友回复：聊天窗口右上角绿色「🤖回复」按钮
 ✔ 身份切换：输入框上方「我 / 对方」按钮切换，自己回复自己信息
 ✔ 通讯录：左侧导航栏 👤 图标进入，查看所有联系人并跳转聊天
 ✔ 朋友圈：左侧导航栏 ⭐ 图标进入，发表动态、点赞、评论
 ✔ 离线运行：安装后 App Shell 由 SW 缓存，无网可用
 ✔ 数据持久化：联系人和聊天记录存 localStorage，刷新/关闭/重启都不丢
 ✔ 手机端自适应：<768px 自动切换全屏布局（聊天/联系人互斥 + 返回）

【兼容性检查（已验证无问题）】
 ① PWA 注册：Service Worker scope 为 ./，与 index.html/sw.js/manifest 同目录
 ② manifest 图标：192x192 和 512x512 均使用 SVG dataURL 内嵌
 ③ 苹果专用 meta：apple-mobile-web-app-capable、apple-touch-icon
 ④ 软键盘适配：iOS 使用 visualViewport.resize 回调防止输入框被遮
 ⑤ 安全区：viewport-fit=cover + env(safe-area-inset-*) 兼容 iPhone 刘海
 ⑥ 头像失败兜底：<img onerror> 失败时自动降级为文字头像
 ⑦ SW 缓存：cache-first + activate 清旧版 + navigate fallback 到 index.html
 ⑧ localStorage 超限：try/catch 包裹 save()，并弹出中文提示
 ⑨ 移动端触控：所有按钮 ≥44px
 ⑩ 输入：Enter 发送 / Shift+Enter 换行，发送后 blur 收起软键盘
 ⑪ beforeinstallprompt：支持的浏览器顶部自动弹安装横幅
 ⑫ 各浏览器 fallback：不支持 beforeinstallprompt 时，点击安装按钮
     弹出含全部主流浏览器操作步骤的中文提示

【常见问题】
 Q1: 页面打开是 404 Not Found？
 A:  GitHub Pages 首次部署后需要 1~3 分钟生效，等一会儿再刷新即可。

 Q2: 手机上看不到「安装」按钮？
 A:  （安卓）先确认你用的是上面列表中的浏览器，然后按对应步骤去
     菜单里找「添加到桌面」或「安装应用」。部分浏览器（如微信自带
     浏览器、夸克浏览器）不支持 PWA 安装，请换 Chrome/华为/小米等。

 Q3: 微信扫完码不能安装？
 A:  微信扫码后默认用微信内置浏览器打开，它不支持 PWA。
     请在微信里点右上角「⋯」→「在浏览器打开」，再安装。

 Q4: 怎么清空数据重来？
 A:  进入聊天页，浏览器地址栏执行：
       javascript:localStorage.removeItem('wechat_sim_v2_pwa');location.reload()
     或者系统设置里清空该站点的网站数据。

 Q5: 换了手机数据能迁移吗？
 A:  目前数据存本机 localStorage，不跨设备同步。如需迁移，可以
     在旧手机浏览器里导出 localStorage，或告诉我你想要云同步功能，
     我可以加一个 JSON 导出/导入按钮。
