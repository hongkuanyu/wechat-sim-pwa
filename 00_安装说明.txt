【公网安装 · 零依赖 · 不用电脑 · 不用同WiFi】
  只需在手机浏览器输入网址：
    https://hongkuanyu.github.io/wechat-sim-pwa/

  ── 安卓手机（所有主流浏览器都支持，任选一个）──

  【推荐 · Chrome】
    1. 打开网址
    2. 页面顶部会弹绿色横幅 → 点「安装」（一步完成）
       如果没看到横幅：右上角 ⋮ → 「安装应用」

  【Edge 浏览器】
    右上角 ⋮ → 「安装应用」

  【三星浏览器】
    右上角 ☰ → 「安装应用」

  【华为浏览器】
    右下角 ▤ 按钮 → 「添加到桌面」 → 弹出提示时点「安装」

  【小米 / 红米浏览器】
    右上角 ⋮ → 「更多工具」 → 「安装应用」

  【OPPO 浏览器】
    底部菜单按钮 → 「添加到桌面」 → 「安装到桌面」

  【vivo 浏览器】
    底部菜单 → 「添加到桌面」 → 「安装」

  【QQ 浏览器】
    底部/右上角菜单 → 「添加到桌面」 → 「安装为应用」

  【UC 浏览器】
    菜单按钮 → 「添加收藏和快捷方式」 → 「添加到桌面」 → 「安装」

  安装完成后：桌面出现绿色「微」字图标，像普通 App 一样全屏运行，
  没有地址栏。首次加载成功一次后，飞机模式（断网）也能点开使用。

  ── 安卓 APK 直装（可选，无需浏览器）──
    本项目已生成 APK 安装包（微信聊天模拟.apk）。
    将 APK 文件传到手机（微信/USB/云盘均可），点击安装即可。
    注意：安装时手机会提示「未知来源」，允许安装即可。
    APK 本质是 TWA 壳，打开后仍加载公网页面，需网络首次访问。

  ── 苹果 iPhone / iPad（必须用 Safari）──

  1. 用 Safari 打开上面的公网网址
  2. 点浏览器底部中间的「分享」按钮（方形+向上箭头）
  3. 向下滑动菜单，找到「添加到主屏幕」
  4. 命名为「微信聊天」→ 点右上角「添加」
  5. 桌面出现绿色图标，点开全屏运行。

  注意：iOS 上 Chrome/Edge/其他浏览器都不支持安装 PWA，必须用 Safari。

【界面说明（微信风格）】

  底部导航栏（4个标签）：
    微信    - 聊天列表和聊天窗口
    通讯录  - 联系人列表，点击进入聊天
    发现    - 朋友圈，发布动态/点赞/评论
    我      - 个人信息、头像设置、数据管理

  聊天窗口输入区（与手机微信一致）：
    左侧语音按钮(🎤) | 输入框 | 表情按钮(😊) | 加号按钮(+)
    · 输入框无文字时显示「+」按钮
    · 输入框有文字时显示「发送」按钮
    · 点击「+」展开功能面板：
      红包(🧧) | 转账(💰) | 语音通话(📞) | 视频通话(📹)
      身份切换(我/友) - 切换当前发言身份

【功能说明】
  ✔ 多联系人：通讯录页面点击「+」添加联系人
  ✔ 自定义头像：
    - 我的头像：「我」页面点击头像进入修改
    - 联系人头像：通讯录中点击联系人头像进入修改
  ✔ 特殊消息卡片：红包、转账、语音通话、视频通话（在「+」面板中）
  ✔ 身份切换：「+」面板中切换"我"和"对方"身份发言
  ✔ 模拟好友回复：聊天窗口右上角「回复」按钮
  ✔ 通讯录：底部「通讯录」标签进入，查看所有联系人并跳转聊天
  ✔ 朋友圈：底部「发现」标签进入，发表动态、点赞、评论
  ✔ 朋友圈以好友身份发动态：发表时可选择好友身份
  ✔ 离线运行：安装后由 Service Worker 缓存，无网可用
  ✔ 数据持久化：联系人和聊天记录存 localStorage，刷新不丢
  ✔ 手机端自适应：全屏布局，适配所有屏幕尺寸

【常见问题】
  Q1: 页面打开是 404 Not Found？
  A:  GitHub Pages 首次部署后需要 1~3 分钟生效，等一会儿再刷新即可。

  Q2: 手机上看不到「安装」按钮？
  A:  （安卓）先确认你用的是上面列表中的浏览器，然后按对应步骤去
      菜单里找「添加到桌面」或「安装应用」。部分浏览器（如微信自带
      浏览器、夸克浏览器）不支持 PWA 安装，请换 Chrome/华为/小米等。

  Q3: 微信扫完码不能安装？
  A:  微信扫码后默认用微信内置浏览器打开，它不支持 PWA。
      请在微信里点右上角「⋯」→「在浏览器打开」，再安装。

  Q4: 怎么清空数据重来？
  A:  进入聊天页，浏览器地址栏执行：
        javascript:localStorage.removeItem('wechat_sim_v2_pwa');location.reload()
      或者系统设置里清空该站点的网站数据。

  Q5: APK 安装后打开是白屏？
  A:  APK 首次打开需要网络加载页面，请确保手机有网络。
      加载成功一次后，后续可离线使用。

  Q6: 「+」面板里的功能怎么用？
  A:  点击输入框右侧的「+」按钮即可展开功能面板，包含：
      红包、转账、语音通话、视频通话、身份切换。
      选择功能后面板自动收起。
