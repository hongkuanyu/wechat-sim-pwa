浏览器安装（推荐）

1
打开手机浏览器（推荐 Chrome），输入上面的网址
2
页面顶部弹出绿色横幅 → 点击「安装」 没看到横幅？点浏览器菜单（⋮）→「安装应用」或「添加到桌面」
3
桌面出现绿色图标，点击全屏运行，没有地址栏
Chrome⋮ → 安装应用
Edge⋮ → 安装应用
华为浏览器▤ → 添加到桌面
小米浏览器⋮ → 安装应用
OPPO浏览器菜单 → 添加到桌面
vivo浏览器菜单 → 添加到桌面
QQ浏览器菜单 → 安装为应用
UC浏览器菜单 → 添加到桌面
⚠ 微信扫码后请在微信里点右上角「⋯」→「在浏览器打开」，微信内置浏览器不支持安装。
📦

APK 直装

1
将 微信聊天模拟.apk 文件传到手机 方式：微信发送 / QQ发送 / USB传输 / 云盘下载
2
在手机文件管理器中找到 APK 文件，点击安装
3
如果提示「未知来源」，点击「允许安装」 路径：设置 → 安全 → 允许安装未知来源应用
部分手机：设置 → 应用管理 → 特殊访问权限 → 安装未知应用
4
安装完成后桌面出现「微信聊天」图标，点击打开
APK 首次打开需要网络加载页面，加载成功一次后可离线使用。APK 本质是 TWA 壳应用，体验与浏览器安装的 PWA 一致。
🔧

打不开？试试这些方法

1
清除浏览器缓存（最常见解决方案） 方法一：浏览器设置 → 隐私设置 → 清除浏览数据 → 选择「缓存」和「Cookie」
方法二：长按桌面已安装的图标 → 卸载 → 重新用浏览器打开网址安装
方法三：在浏览器地址栏输入以下地址清除站点数据：
chrome://settings/content/siteDetails?site=https://hongkuanyu.github.io
2
换一个浏览器试试 如果当前浏览器打不开，请换用 Chrome / Edge / 华为浏览器 / 小米浏览器 中的一个。
注意：微信内置浏览器、夸克浏览器不支持 PWA 安装。
3
APK 安装后白屏？ ① 确保手机有网络（首次打开需要加载网页）
② 等 1-3 分钟后重试（GitHub Pages 刚更新，CDN 缓存可能未刷新）
③ 如果持续白屏，可能是 TWA 验证未通过，会显示地址栏但仍可使用
4
APK 提示「安装失败」？ ① 检查手机是否允许「安装未知来源应用」
② 检查手机存储空间是否足够（APK 仅 865KB）
③ 检查 Android 版本是否 ≥ 5.0（API 21）
④ 部分手机（华为/小米）需在「手机管家」中关闭「纯净模式」
5
看不到「安装」按钮？ ① 先清除缓存（见方法 1），再重新打开网址
② 用浏览器菜单（⋮）手动找「安装应用」或「添加到桌面」
③ 如果菜单里也没有，说明该浏览器不支持 PWA，请换 Chrome
6
页面加载很慢或 404？ GitHub Pages 刚更新后可能需要 1-10 分钟生效。请等待几分钟后刷新重试。
如果持续 404，请检查网址拼写是否正确。
